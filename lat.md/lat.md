# Success Manager

An unbiased supervisor for coding projects: worker Claudes do the work, an independent QA script decides pass/fail, and a pixel-art office shows the crew.

Start here. Each file below is one area; follow its links to the exact code.

- [[engine]]: the `sm` CLI, Claude Code hooks, QA detection, reviewer sweeps.
- [[missions]]: the Floor Manager pipeline: plan, delegate to a parallel team, review, report.
- [[crew]]: roster, rooms, department training (skills) and MUSE ideas.
- [[guard]]: what each worker role may and may not touch.
- [[office-ui]]: the Pixel Agents fork that renders the office and its `/sm/*` API.
