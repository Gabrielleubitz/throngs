# Data story

Use only the real data given. Structure: the one headline number -> the chart that proves it -> 1-2 supporting comparisons -> what it means.
- Animate bars, lines and counters with interpolate() (count up with Math.round), ease with spring, label directly (no legends), start axes at zero, cite the source on screen. One chart per scene.
- Colour: one accent for the point, grey for the rest.
Build it with the remotion-video skill (setup, render, ffprobe check, hand back the .mp4 path in the "video" field).
