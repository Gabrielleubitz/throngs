# Event teaser

Structure: curiosity hook -> what (name) -> when and where in huge type -> one reason to come -> call to action (register/link). 10-20 s, 9:16 for stories or 16:9 for the site.
- Date, time, place and price must come from the request; if any is missing, ask the owner. Optional countdown component driven by frame.
Build it with the remotion-video skill (setup, render, ffprobe check, hand back the .mp4 path in the "video" field).
