# Explainer video

Goal: one idea understood. Structure: question or pain -> the simple model (3 parts max, drawn as shapes/icons that build up) -> example -> takeaway.
- Draw with SVG/shapes animated by interpolate(); reveal one element per sentence; keep a constant visual metaphor.
- Narration is the spine: write the script first (about 150 words per minute), voiceover it, then time scenes to the audio length.
- Captions on, plain words, no jargon.
Build it with the remotion-video skill (setup, render, ffprobe check, hand back the .mp4 path in the "video" field).
