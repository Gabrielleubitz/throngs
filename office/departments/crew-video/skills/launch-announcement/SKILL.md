# Launch announcement

Structure: "New" hook with name/version (0-3 s) -> the headline change shown in action -> 2-3 supporting changes as quick cards -> where/when it is available + call to action.
- Pull the facts (names, dates, numbers) from the changelog, README or request; never invent. Clean, confident motion, brand colours, 15-30 s.
Build it with the remotion-video skill (setup, render, ffprobe check, hand back the .mp4 path in the "video" field).
