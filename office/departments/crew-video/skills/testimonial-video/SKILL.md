# Testimonial video

Use ONLY real quotes the owner provides (verbatim, with name and role/company). Never write or improve a quote.
- Structure: big quote text animating in phrase by phrase -> name, role, optional star rating or photo -> result number if supplied -> logo + call to action. 15-30 s; several quotes = one scene each.
- Calm pacing, large type, generous space.
Build it with the remotion-video skill (setup, render, ffprobe check, hand back the .mp4 path in the "video" field).
