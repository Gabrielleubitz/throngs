# Tutorial video

Structure: what you will have at the end -> numbered steps (step number badge + short title + the screen or code) -> recap -> next step.
- One action per step, hold each long enough to follow (min 3 s), highlight the exact spot (box, arrow, zoom). Code steps: show typed code with syntax colours (see the code-hike template in references/templates.md).
- Chapter markers: give the owner a timestamp list in the report.
Build it with the remotion-video skill (setup, render, ffprobe check, hand back the .mp4 path in the "video" field).
